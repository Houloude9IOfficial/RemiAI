# RemiAI v2.0.0

**RemiAI v2.0.0** is the next major release, built on the `v1.6.0` branch. It focuses on polishing the daily experience: a much smarter chat composer, a resizable per-chat file workspace, deeper personalization, and a redesigned marketing website.

---

## Highlights

### Chat Experience

- **Centered empty-chat composer** — new conversations start with a clean, focused input in the middle of the screen that smoothly expands to the full chat input
- **Auto-generated chat titles** — conversations are named for you in the background, no more "New Chat"
- **Regenerate flow** — re-roll AI responses, with media previews and streaming range support
- **Smarter rendering** — Markdown rendering applies to AI messages and attached files only, with refined message lists and tool-call visualizations
- **Conversation rows are clickable per mode** — cleaner navigation between chat modes
- **Localized time & search** — chat timestamps and search respect the user's timezone and region context
- **Generating indicator & faster timer** — clearer status while the AI works

### Session Files & File Manager

- **Session-files sandbox with URL support** — files can be referenced by URL, and uploads land in the chat's session sandbox where the AI can access them
- **Single-file session panel** — open and manage one file at a time with a cleaner panel
- **Resizable session files panel** — drag to size the panel to your liking
- **FileEditor improvements** — better UX, theme integration, and markdown-aware rendering of attached files

### Reliability & Error Handling

- **Automatic retries** — failed AI requests retry up to 3 times before erroring out
- **Structured stream errors & tool timeouts** — cleaner failures with real messages instead of silent hangs
- **Interrupted-run detection** — detects interrupted runs and emits a resumable error state
- **Decoded tool errors** — clearer filesystem-access error messages
- **Raised agent limits** — deeper sub-agent spawning and larger tool results

### Personalization

- **User-selectable accent color** — pick a color that matches your style (Settings → Customize)
- **Enhanced About modal** — richer app info in the sidebar

### Sidebar, Shortcuts & UI Polish

- **Global keyboard shortcuts** — a shortcuts UI with hooks for quick actions, accessible from the sidebar footer
- **Sidebar refactor** — conversation grouping and navigation tweaks
- **Theme refinement** — reworked global theme tokens, deeper dark mode, refined chat input spacing
- **SVG cards in shadow DOM** — tool visuals stay clean and theme-safe
- **Mobile polish** — sticky mobile headers and 100dvh layouts
- **PWA improvements** — enhanced PWA asset setup for installability

### Website

- **Full redesign** of the marketing website with new screenshots
- **SEO & PWA asset setup** — better discoverability and installability for the site

### Creations

- **Particlefield** — a new AI-built generative particle art playground added to the [creations](./creations/Particlefield/) collection
