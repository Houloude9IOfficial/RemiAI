# Morse Code Converter

A simple command-line tool that converts text to Morse code.

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/Houloude9IOfficial/RemiAI.git
   ```
2. Navigate to the project directory:
   ```sh
   cd creations/TextToMorseCode
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```

## Usage

1. Run the tool:
   ```sh
   npm start
   ```
2. Enter the text you want to convert to Morse code when prompted.
3. The Morse code will be displayed in the console.

## Example

```sh
$ npm start
Enter text to convert to Morse code: Hello World
Morse code: .... . .-.. .-.. --- / .-- --- .-. .-.. -..
```
